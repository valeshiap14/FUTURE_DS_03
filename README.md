# FUTURE_DS_03

# Marketing Funnel & Conversion Analysis

**Author:** Val  
**Tool:** Python (Jupyter Notebook)  
**Dataset:** User Behavior Data (700 users)

---

## Overview
This analysis examines user engagement and progression through the platform's engagement funnel. It identifies drop-off points and calculates conversion rates to inform strategies for improving retention and engagement.

---

## Funnel Stages

| Stage | Description |
|-------|-------------|
| 1     | Low — minimal engagement |
| 2     | Low-Medium — slightly active |
| 3     | Medium — moderate engagement |
| 4     | Medium-High — higher engagement |
| 5     | High — very active, most valuable |

---

## Users per Stage

| Stage | Users |
|-------|-------|
| 1     | 136   |
| 2     | 146   |
| 3     | 143   |
| 4     | 139   |
| 5     | 136   |

---

## Key Insights
- Stage 2 has the most users; Stage 1 and 5 have the fewest.  
- Drop-offs occur mainly in mid-funnel stages (Stages 2–4).  
- High-value users (Stage 5) are small but critical for retention and revenue.  

---

## Recommendations
1. Improve early engagement to move Stage 1 → 2.  
2. Guide mid-level users (Stages 2–4) to higher engagement.  
3. Retain high-value users (Stage 5) with loyalty programs or exclusive features.
